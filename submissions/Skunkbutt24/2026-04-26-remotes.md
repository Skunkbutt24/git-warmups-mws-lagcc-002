## What I learned or re-learned
I learned that `git remote -v` shows the remote repositories connected to my local repo. In this repo, `origin` points to my GitHub fork, which is where I push my branch.

I learned that `git fetch origin` downloads new information from GitHub but does not merge it into my current branch. `git pull` does more because it fetches and then brings the remote changes into my local branch.

I also learned that `origin` is the default name for the remote repo I cloned from, while `upstream` is often used for the original instructor or organization repo when I am working from a fork. The `-u` in `git push -u origin Skunkbutt24` sets the upstream tracking connection, so later I can just use `git push` or `git pull` without typing the remote and branch every time.

## What still feels slow
I still need more practice understanding the difference between my fork as `origin` and the instructor repo as `upstream`.
