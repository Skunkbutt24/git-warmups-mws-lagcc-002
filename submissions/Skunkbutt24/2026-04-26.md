git status

git commit -m "chore: add scratch file a"  
rm scratch-a.txt scratch-b.txt  

## What I learned or re-learned
I learned that the staging area is where Git holds the changes that will go into the next commit. git add puts a file into the staging area, while git commit saves the staged change into the project history. I also learned that git restore --staged removes a file from staging without deleting the file from my folder.

## What still feels slow
I still need more practice understanding the difference between untracked, staged, and committed files.
