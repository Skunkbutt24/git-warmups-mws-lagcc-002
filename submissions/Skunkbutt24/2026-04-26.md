## What I learned or re-learned
I learned that `git checkout -b` creates a new branch and switches to it at the same time. Without `-b`, `git checkout` only switches to an existing branch. Branches exist so I can work on changes separately without affecting the main branch or my personal branch. I also learned that `git branch -d` safely deletes a branch only if Git thinks it has been merged, while `git branch -D` force deletes it even if it has unmerged work.
