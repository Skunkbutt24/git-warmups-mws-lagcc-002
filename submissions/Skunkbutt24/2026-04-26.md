## What I learned or re-learned
I learned that git status shows the current condition of my working directory. It can show modified files, staged files, untracked files, or that there is nothing to commit. Modified means Git is tracking the file and the file changed, but it has not been staged yet. Staged means the file was added with git add and is ready to be committed. Untracked means Git sees a new file, but it is not tracking it yet.

I also learned that git log --oneline shows each commit in a short format. Each line usually has a short commit hash first, then the commit message. The --graph option draws the branch history visually, showing how commits, branches, and merges connect. git diff shows the exact changes in unstaged files. If there are no changes, git diff shows nothing.
